1. 只识别截图中明确可见的文字，不得推断或补全。
2. 无法看清、截图中不存在或无法确认的字段，填写“待核验”，并将对应的英文字段名加入 `uncertain_fields`。
3. 提取字段对应的值，不要把字段标题写入结果。
4. 数值和单位按照截图原文填写，不得换算。

6. 只能返回一个合法 JSON 对象，不得输出分析、解释、标题、思考过程或 Markdown 代码块。

{
  "transaction_date": "",

  "transaction_area": "",
  "transaction_price": "",
  "land_location": "",
  "land_usage": "",
  "uncertain_fields": [],

返回前检查：输出必须以 `{` 开头、以 `}` 结尾，并且 JSON 前后不得出现任何其他文字。
